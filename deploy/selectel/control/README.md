# Control host evidence sampler

`sampler.py` measures only fixed paths on the Selectel host: `/opt/memoly`, its durable media directory, and its backup directory. It reports statvfs measurements and once-per-UTC-day bounded walks of current regular-file lengths. Each inventory skips symlinks and fails atomically on any scan/stat error, after 125,000 entries or 12 seconds; the two walks together remain under the service's 30-second deadline. Values are logical file bytes and are not family quota, database, or allocated disk estimates.

The sampler atomically writes `/opt/memoly/control/metrics/snapshot.json`. `/opt/memoly/control` and `metrics` are root-owned mode 0755; the snapshot is root-owned mode 0644 so the `bun` container user can read it. Every executable and output ancestor is checked for symlinks, non-root ownership, and group/world write access before the sampler runs. The backend and scheduler receive only `metrics` read-only; worker does not. The app has no host root or docker socket access. Telemetry retention deletes at most 1,000 rows per table per minute, allowing 100-day retention to keep pace with activity while every cleanup remains bounded.

Install this service, timer, and reviewed sampler only through the guarded release procedure while it holds the Selectel release lock. The timer executes the copied root-owned `/opt/memoly/control/sampler.py`, never the memoly-owned checkout. The last-successful-release receipt is `/opt/memoly/control/release-evidence.json`, root-owned mode 0600. Backup evidence is `/opt/memoly/backups/control-evidence.json`, root-owned mode 0600, and contains only `artifactAt`, `validation` (`valid`, `invalid`, or `unknown`), and `restoreTestAt`. The current producer validates a non-empty PostgreSQL custom archive and a non-empty `pg_restore --list` table of contents; the UI calls this a structural check, not a restore test, so `restoreTestAt` remains null. Artifact presence alone is not validation or restore evidence. No paths or artifact names are emitted.

The Python unittest uses temporary synthetic directories. Run locally with `python -m unittest discover -s deploy/selectel/control -p '*test*.py'`.
