# Границы

- Проект Bun/Hono/Prisma, React/Vite, contracts package. Один task worktree; production и локальный main не используются для разработки. Никаких новых зависимостей.
- Existing entries/get/PATCH/clear responses remain strict legacy when view omitted. Explicit `view=month-summary` for list, detail, metadata PATCH, clear; list returns the same DTO base with empty sources and additional optional `month` field only on opt-in. `month: {cover: AlbumSourceDto|null, coverSourceId: string|null, photoCount: number, otherCount: number, discussionGeneration: number, membershipEpoch: number}`. sourceCount remains exact available total. For legacy oversized collection, list can return bounded compatibility summary without extra fields and full write refuses with update guidance; direct detail rejects rather than returning a partial collection.
- GET same `.../entries/:entryId/sources?kind=photo|other&cursor=...` returns `{items, nextCursor}` in saved order with cover excluded from photo pages. Summary exposes cover regardless of its page. Choose cover using PUT `.../:entryId/month-cover` `{expectedVersion, sourceId: uuid|null}`, version is entry.version. DELETE `.../:entryId/photos/:sourceId` If-Match entry.version removes a photo association only. Both return summary entry or 204 as appropriate. Old PUT /sources stays bounded and guarded.
- POST `.../:entryId/photo-batches`, idempotency key, `{discussionGeneration,membershipEpoch,count}` reserves contiguous slots; returns `{grant}`. POST `.../:entryId/photos`, idempotency key, `{grant,offset,source}` attaches one photo, 204. Stable client UUIDs per batch and file. Grant binds scope, entry, actor, session, epoch, generation and reservation; reject stale context before any write or replay. Skip optional pilot notification on this new direct append path per brief.
- Agent A owns backend albums/Prisma/contracts. B owns PhotoComposer reuse, month queue and picker. C owns page/detail/editor/CSS and viewer adapter. No simultaneous edits to shared contract or schema. Test on isolated PostgreSQL month_collage_test and own storage. Production recovery proof before guard binding or deployment.
