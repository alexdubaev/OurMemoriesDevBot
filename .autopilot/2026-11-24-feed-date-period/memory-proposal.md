# Предложение для памяти проекта

- Из корня рабочей копии запусти `bun run --cwd webapp e2e --config=e2e/memoly-v4.playwright.config.ts -g 'mobile feed applies and clears a family timezone date period'`. Сценарий проверяет применение месяца, UTC-границы в запросе и сброс периода на мобильной ширине 320 px. Он использует браузерный fixture с подменённым API.
- Границы календарного периода вычисляются отдельно в часовом поясе семьи в `webapp/src/features/feed/date-period.ts`. Верхняя граница исключающая. При смене периода начинай пагинацию заново: курсор обычной ленты и ленты непрочитанного привязан к обеим границам.
