# Интерфейсы и проверки

## Границы, решённые в спецификации

- Контракт списка воспоминаний принимает необязательную пару ISO UTC `occurredFrom` и `occurredBefore` ([включительно, исключительно)). Обе границы должны присутствовать вместе, первая должна быть раньше второй. Без пары сохраняются запросы прежних клиентов и старые курсоры. Репозиторий применяет фильтр к `occurredAt` и до ограничения страницы. Курсоры списка и непрочитанного проверяют соответствие границ вместе с другими фильтрами.
- Период ленты хранит календарный выбор без времени (`year`, `month`, `range`, `day`), переводит выбор в UTC перед запросом, учитывает IANA-зону семьи. Стабильные ключи кэша и проверки новых записей включают активный период. Проверка наличия записей без меток работает на всю семью. Постоянное хранилище периода не требуется.
- Вёрстка остаётся внутри текущей ленты. Используем MemolyBottomSheet и существующие иконки и календарь. На ширине 320–430 CSS px заголовок и кнопка не должны пересекаться или выталкивать навигацию за край.
- Швы проверки: контракт запроса, подписанный курсор, backend integration с PostgreSQL и сценарий mobile V2 в текущем Playwright fixture с проверкой исходящих фильтров. Границы локального дня, месяца и диапазона проверяются по точным UTC значениям.

## Проектные правила

Официальный источник — `origin/main` репозитория alexdubaev/OurMemoriesDevBot. Рабочий каталог для изменения — этот worktree. Актуальные `AGENTS.md`, `docs/development/SMALL_CHANGE_WORKFLOW.md` и `docs/TESTING.md` имеют силу. Сохраняем действующие ограничения доступа и Media ACL. Публикация только с gate/evidence, которые применяет проект. Прод окружение и данные не используются в проверках. Правила и решения предыдущих релизов за пределами ленты остаются в `.autopilot/PROGRESS.md`.

Стек существующего monorepo, версии в package.json и bun.lock. Зависимости уже установлены `bun install --frozen-lockfile`. Пакеты и lock-файл не изменяем. Проверка проекта: документированный FULL через `bun run verify:local` в WSL и узкий mobile сценарий, который тестирует новую функцию. Узкий тест дат: `bun run --cwd webapp test <файл>`; Playwright: `bun run --cwd webapp e2e --config=e2e/memoly-v4.playwright.config.ts -g '…'`. Запуск backend integration по `docs/TESTING.md`, с отдельной тестовой БД.
