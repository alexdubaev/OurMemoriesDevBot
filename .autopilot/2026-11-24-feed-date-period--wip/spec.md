# Фильтр дат в ленте Memoly

## Задача

Открыть воспоминания из любого нужного периода прямо из ленты, используя актуальный интерфейс со скриншота «Фото 1.jpg». Реализация ведётся через Autopilot.

## Решение

- R01. Справа от «Лента воспоминаний» появляется кнопка с иконкой календаря и подписью «Даты». По рекомендациям ui-ux-pro-max кнопка находится рядом с областью действия, её область касания от 44 × 44 px, а на узком экране остаётся иконка с доступным названием «Даты». Лист выбора использует существующие панели Memoly.
- R02. Режим «Год» выбирает целый календарный год.
- R03. Режим «Месяц» выбирает месяц в указанном году.
- R04. Режим «Диапазон» выбирает первый и последний месяц, включая их целиком. Годы могут отличаться. При обратном порядке полей панель объясняет ошибку и не применяет выбор.
- R05. Режим «День» показывает календарь и выбирает один день в часовом поясе семьи, включая дни смены времени.
- R06. «Показать» применяет период. Под заголовком появляется компактная подпись применённой даты с крестиком для сброса. При повторном открытии панель показывает применённый выбор. Закрытие панели сохраняет применённое значение.
- R07i. Период действует на всю выдачу, включая старые страницы и режим непрочитанного, с исходной хронологией. Пустой период показывает «За этот период записей нет» и оставляет возможность сброса. Период ограничен текущей семьёй. При ошибке запроса существующий повтор сохраняет выбор.

## Решения по реализации

Используем текущие React, TypeScript, React Query, UI-примитивы Memoly и PostgreSQL. Переводим календарный период семьи в UTC-границы на клиенте. API применяет границы к дате воспоминания до выдачи страниц. Курсор сохраняет условия запроса. Используем существующий порядок, ограничения видимости и условия доступа.
