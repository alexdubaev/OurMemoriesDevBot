# F1 — Ошибка сети не прячет картинку из кэша

**Требования:** R03, R03.1
**Зависит от:** —
**Зона:** `webapp/src/platform/media/use-private-image-url.ts` · `webapp/tests/private-image-*.test.ts*`
**Волна:** 3
**Ревью:** да — ремонт ветки
**Модель:** сильная

## Что должно заработать

Если сеть отказала (офлайн, таймаут, 5xx) раньше, чем прочиталась картинка из кэша, плитка не мигает «Нет миниатюры»: она дожидается результата кэша и показывает картинку из него. Ошибку она показывает, только если в кэше ничего нет.

## Из брифа, дословно

> «фотографии в альбомах появляются с задержкой»

## Разделы спецификации

Истории 8, 9. Решение «Загрузка картинок». Граница U4.

## Критерии приёмки (находка ревью ветки, дословно)

- [ ] Craft · `webapp/src/platform/media/use-private-image-url.ts:295`: ошибка сети (офлайн/таймаут/5xx), пришедшая раньше чтения кэша, сразу ставит `loaded` с `url: null` (плитка «Нет миниатюры») и вызывает `onSettled` — 300–600 мс мигание «Нет миниатюры», затем картинка из кэша. До ветки кэш читался первым, этой вспышки не было. Ожидаемо: при сетевой ошибке, если чтение кэша ещё в полёте, дождаться его результата и только затем ставить `url: null`/`onSettled`. Нужен один unit-тест «сеть отказала раньше чтения кэша».
- [ ] 401/403/404 по-прежнему сразу гасят копию из кэша, даже если чтение ещё идёт. Существующие тесты не ослаблены.
- [ ] `bun run typecheck`, `bun run lint`, `bun test tests` в `webapp/` зелёные.
