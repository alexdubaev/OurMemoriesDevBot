## Назначение

Отдельная закрытая веб-страница владельца сервиса: все семьи, уникальные пользователи,
их членства, активность, хранилище и состояние интеграций. Это не раздел семейного приложения
и не интерфейс для просмотра чужих фотографий, переписки или выдачи прав.

## Читать в таком порядке

1. Корневой AGENTS.md и `.agents/skills/teamlead-development/SKILL.md`.
2. `SPEC.md` — продукт, граница доступа, API, эксплуатация.
3. `DATA_MAP.md` — реальные таблицы и определения показателей, включая пробелы данных.
4. `PLAN.md` — три последовательных этапа, тесты и выпуск.
5. `START_PROMPT.md` — задание исполнителю.
6. `VERIFICATION.md` — что проверено при подготовке пакета, а что ещё нет.

## Эталон дизайна

В `reference/memoly-owner-dashboard-demo.html.gz` сохранён исходный самодостаточный
HTML без изменений, в стандартном gzip. Архив не содержит реальных данных.
Чтобы получить исходный HTML, выполнить из корня репозитория:

```sh
node docs/mvp/owner-dashboard/reference/restore-reference.mjs
```

Результат: `.scratch/memoly-control-reference/memoly-owner-dashboard-demo.html`.
Открыть файл в браузере. Интернет и зависимости не нужны. Скрипт сверяет SHA-256.
Архив — упаковка визуального референса, не production-бандл.

Эталон сохраняет шесть экранов, мобильную навигацию, карточки, таблицы и боковые подробности.
Числа, имена, графики, «работает» и даты в нём демонстрационные. В рабочей панели их заменить
реальными API-значениями или честными состояниями «нет данных». Формулы определяет DATA_MAP,
а не визуальные подписи макета. Inline SVG в замороженном HTML не является разрешением
копировать их в production: действуют WebP/icon rules AGENTS.md. Пользовательские тексты
нельзя выводить через innerHTML. Макет не является безопасным шаблоном для подключения БД.

## Принятые технические границы

Предлагаемый адрес первой версии: `https://app.memoly.ru/control/`.
Отдельный HTML entry и React root; семейный App не монтируется. Тот же origin и backend
уменьшают объём инфраструктуры. Отдельный домен/сервис не обязателен и сейчас не создаётся.
Панель читает новый owner-only API. Источники хранения и мониторинга подключаются
серверными адаптерами; браузер не получает инфраструктурные ключи.

Публикация этого пакета — docs/reference-only. Она не включает установку панели,
выдачу доступа, миграции или production deploy. Когда исполнитель получает START_PROMPT,
он реализует назначенную панель и доводит её до штатного проверенного выпуска.

## Чего не делать

Не менять UI v4 для семей; не продолжать заново завершённые media/UI задачи.
Не смешивать пользователя, сессию и членство. Не суммировать серверный диск, БД и S3.
Не считать токен сессии доказательством присутствия онлайн. Не превращать каждый экран
в прямой опрос облачного провайдера. Не выдавать отсутствие измерения за ноль.
