# Дополнительный статический шадцн-референс

Файл `shadcn-layout-guide.html` — **компактная структурная иллюстрация** принятого дизайна, без внешних зависимостей и без скриптов. На нём можно открыть все шесть разделов, даже если просмотрщик iPhone блокирует JS.

Это **не побайтовая копия** оригинального `memoly-control-shadcn-fixed.html` из беседы, не исходники React и не эталон API. Исправленный оригинальный прототип и исходный ZIP были переданы владельцу отдельно. Новый дизайн в письменном виде зафиксирован в `../DESIGN_SHADCN.md`. Реализовать продуктивную панель нужно из настоящих shadcn/React компонентов, а не копировать HTML guide.

Все числа, имена и статусы в guide демонстрационные. Старый зелёный файл `memoly-owner-dashboard-demo.html.gz` отвергнут и никогда не является источником UI.
