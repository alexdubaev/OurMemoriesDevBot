# Графика и производительность · WebP only для собственных иконок
## A. Что должен делать агент
Использовать готовый согласованный набор `../../assets/icons/`. Если нужен новый значок, самому создать/сгенерировать его в том же стиле на этапе разработки, оптимизировать и добавить в manifest вместе с назначением. Не искать случайные PNG в интернете и не добавлять вторую библиотеку. Не вставлять весь экран картинкой вместо настоящего UI.

Иконки и иллюстрации: **WebP с альфа-каналом**, прозрачность настоящая, не нарисованная шахматная подложка и не белый фон. Запрещены SVG generation, inline SVG, SVG sprite/data URI и icon fonts. Допустимы HTML/CSS для layout, спиннера, полей, прогресса и реальной waveform; они не заменяют графический asset. Native browser/video controls не являются поставляемой приложением графикой.

## C. Подключение
`WebpIcon` получает semantic name, состояние, размер; URL выбирается из manifest. `img` width/height заданы, srcset для2x/3x, alt пустой при подписанной кнопке. Кнопка имеет aria-label, hit-area44px и focus. Не маскировать отсутствие файла невидимой иконкой. Assets загружаются локально с нашего origin, не с внешних icon-CDN.
Shadcn/Base UI и PhotoSwipe остаются библиотеками поведения; их SVG icons заменить через официальные slots/render callbacks. Не форкать библиотеку целиком ради значка. Проверить также автоматически добавленные chevrons/close/check внутри select/dialog.

## D. Производственный pipeline
Resize с качественным ресемплингом → WebP encode → strip EXIF/GPS/ненужного metadata → проверить alpha и размеры → визуальный review на светлом/тёмном фоне → checksum и manifest. Удаление metadata относится к создаваемым UI-ресурсам и preview, а не к обещанной байтовой копии пользовательского оригинала.
Не передавать в bundle большие PNG мастера, raw generation boards, screenshots, demo и историю. На первый экран грузить только используемые значки; изображения ниже fold lazy. Не загружать видео целиком для poster. Cache immutable только для публичной версионированной UI-графики; семейные файлы подчиняются auth/no-store политике.
Измерять размер загруженных ресурсов, не просто считать размер папки. Alpha edge без halo на #FBF8F5 и #FFFFFF, без теней внутри маленькой пиктограммы. Оптимизация не должна делать иконки размытыми.

## E. Комплект
`assets/manifest.json` содержит runtime и demo с размерами, alpha, byte size, SHA256. `references/` — визуальные справочные файлы, не runtime. `tools/build_reference_assets.py` воспроизводит простой оригинальный растровый набор без SVG и рендерит статические референсы; он не добавляет AI в приложение.
Семейные фото в этом пакете — синтетические фрагменты созданного AI-концепта, не данные настоящих семей. Это прототипные изображения, не финальный пользовательский контент.
