# design.md — точная реализация интерфейса
**Вариант 1 «Классическая лента» · MVP v2.4 · 9 сентября 2026.**

Нормативный документ для frontend-агента. Брендбук объясняет характер; этот файл задаёт размеры, композицию, состояния и поведение. Сгенерированная картинка — направление, не пиксельный исходник. При конфликте функций с картинкой действует минимальный состав MVP ниже.

## D00. Что сохраняем и что исключаем
Сохраняем тёплый почти белый фон, белые карточки, широкий снимок, время/автора, спокойный коралл, отдельные аудиокарточки. Удаляем с макета лупу (поиска нет), «События», календарь, общую галерею, меню «Ещё» и дублирующий FAB. Не рисовать лайки12, комментарии3 или другие fake metrics: это не вариант2/5.

Нижняя навигация: **Лента · Добавить · Семья**. «Добавить» — действие sheet, не страница/route. В viewer-режиме центр — неинтерактивная метка «Просмотр», а элементы навигации сохраняют позиции.

## D01. Размеры и платформа
Канонический fixture viewport **390×844 CSS px**. Это весь тестовый browser viewport без нарисованного корпуса телефона и status bar. В реальном Telegram учитывать доступный viewport и safe/content insets из HostBridge. Использовать `100dvh` с fallback, не фиксировать height844. Нельзя дважды сложить CSS safe-area и Telegram safe-area: HostBridge возвращает уже нормализованные значения для текущего режима.

В MVP Mini App раскрывается обычным `expand`, без обязательного fullscreen. Header Telegram, Close и системная батарея — элементы хоста, не HTML интерфейса. App content max-width480px на широком экране, центрирован, фон по бокам canvas; на360/375/390/430 занимает ширину полностью. Отдельный desktop dashboard не строить.

Root background `canvas`; основной scroll container один. Header прокручивается с лентой, bottom nav fixed/sticky снизу с корректным safe inset. Внутри full-screen photo viewer scroll заблокирован и восстанавливается после закрытия.

## D02. Токены
Единственный источник `design/tokens.json`, CSS-копия `design/tokens.css`. Не выбирать «похожие» значения Tailwind по вкусу. Внедрить как semantic variables без конфликтов с базовыми shadcn variables; имеющиеся семантические имена настроить через mapping.

Визуальные значения: canvas#FBF8F5; surface#FFFFFF; text#302A2E; muted#756A71; accent-soft#F4A4AE; accent-strong#A83750; line#E8DFDA. Inter400/500/600/700, fallback system.

Space scale:4,8,12,14,16,20,24,32. Card radius16, field radius12, sheet radius24 сверху, pill999. Card shadow `0 2px 10px rgba(48,42,46,.045)`, без тяжёлой внешней рамки. Divider1px line. Область клика минимум44×44, основной field/button height48.

## D04. Каноническая лента: вертикальная анатомия
При390px ширины и safe-inset0:
1. Верхний заголовок: horizontal16, top16, height28. Текст20/28 semibold. Справа icon-button MoreHorizontal44×44, но он открывает только help/privacy — не поиск.
2. Блок ребёнка: margin-top12, height48. Аватар40×40; gap10; имя16/22 semibold; возраст/«Семейная лента»12/18 muted. Пример «Варя» только synthetic fixture. При отсутствии birthDate — «Семейная лента».
3. Фильтры: margin-top16, row44, gap8, horizontal overflow без обязательного видимого scrollbar. Chip height36, px12, radius999, text13/18 medium; активный accent-tint+accent-strong; остальные surface+muted. Все пункты должны быть достижимы свайпом/клавиатурой.
4. Дата: margin-top20, bottom10; text15/22 semibold.
5. Карточки: width358 (390−2×16), gap12. Другая дата margin-top24. Одно фото в карточке aspect4/3: media box358×268.5; rounding лишь верхние углы16. Body14; caption15/22; metadata row margin-top8 min44.
6. Bottom nav: base68 + safeBottom; surface white, border-top1 line. Content bottom padding=nav height+16. Никакого floating plus поверх фото.

Эти координаты описывают flow, не absolute positioning текста. При200% text или длинном имени блок растёт, соседние блоки сдвигаются, не перекрываются. Нельзя растягивать картинку, чтобы подогнать высоту экрана.

## D05. Header и профиль
Wordmark «Наши воспоминания»; child-name max2строки, затем ellipsis; название семьи показывать на странице Семья, не дублировать четыре заголовка на главной. Avatar-letter fill accent-tint, letter accent-strong16semibold. Аватар не придумывает фото ребёнка из профиля Telegram взрослого.

Возраст вычисляется относительно local today семьи, склонения русские; не показывать медицинские метрики. «2 года 7 месяцев» в fixture — образец, не число в коде. Годовщины/первые события автоматически не определяются.

## D06. PhotoMemoryCard
Фото box4/3, object-fit cover, default object-position center. Оригинал неизменен; tap открывает весь снимок contain в viewer. При2–10 фото — горизонтальный swipe внутри box, счётчик «1 / 3» в правом верхнем углу12px с читаемой полупрозрачной тёмной подложкой. Без masonry и огромной сетки.

Ниже body14px; подпись максимум4строки, затем кнопка «Читать полностью» в детали. Если подписи нет, не выводить «Без описания» — сразу metadata. Meta: слева «14:32 · Александр», справа Heart с count только если>0, зона44×44. Кнопка more44 в доступной строке действий детали; не накладывать маленькую опасную delete-иконку на лицо ребёнка.

Сердечко outline muted, active fill accent-strong. optimistic update с rollback/error-toast; double taps не создают два лайка. Для a11y aria-pressed, label «Поставить сердечко»/«Убрать сердечко».

## D07. VideoMemoryCard
Та же геометрия и текстовая часть. Poster4/3, Play56 круг в центре, duration12/18 на контрастной подложке справа снизу12. До play не скачивать весь ролик; `preload="none"` или `metadata` при необходимости, poster lazy. **HTML5 `<video>` / `HTMLMediaElement` — готовый media engine; собственный decoder/player engine не писать.** В Mini App рисуем только наш React-слой управления над приватным playback source.

В detail: тёмный фон `#151315`; video `object-fit:contain`; `playsInline`; autoplay запрещён. Наши controls: Play/Pause44, seek-track минимум4px с touch-zone44px, время `текущее / общее` 12/18, fullscreen44; системную громкость отдельным контролом в MVP не дублировать. Controls исчезают после короткого бездействия только во время playback и возвращаются по tap. На pause/end остаются видимыми. Escape/Back/Close останавливает video и освобождает source/object URL. При доказанной несовместимости custom controls на поддерживаемом WebView допускается fallback `controls`, но не второй media engine и не отдельный player framework.

Пока rendition pending: вместо play текстовый блок «Видео сохранено. Готовим просмотр» и спиннер. Failed rendition: «Не удалось подготовить просмотр» + повтор (full) и «Скачать исходник» (member), если original stored. Source import failed: не показывать это как доступное видео всем участникам.

## D08. VoiceMemoryCard
**HTML5 `<audio>` / `HTMLMediaElement` — движок воспроизведения; собственный audio engine не разрабатывать.** Нативный audio element может быть визуально скрыт, но остаётся источником `play`, `pause`, `currentTime`, `duration`, `ended`, `timeupdate` и ошибок. React-компонент только отображает и синхронизирует эти состояния.

Card padding14. Первый ряд min52: Play/Pause44×44 круг accent-tint, icon accent-strong20; gap12; waveform растягивается flex; duration справа12/18 min36px. Waveform содержит48 **измеренных** peaks из server-side подготовки, не random CSS и не растровую картинку; выполненная часть accent-strong, остальная более бледная линия. Нажатие/drag по waveform меняет `currentTime`; touch-zone по высоте минимум44px. При idle справа общая длительность; во время проигрывания допускается показывать прошедшее время, но формат должен быть единым во всех voice cards.

При no peaks — стандартный progress slider; форма волны не обязательна для выпуска. Seek с клавиатуры/VoiceOver, label «Позиция воспроизведения». Подпись ниже с margin12; metadata/heart как у фото. Если подписи нет, не рисовать пустой placeholder. Headline «Голосовое сообщение» использовать для a11y/детали, а не как обязательную крупную строку каждой карточки.

Одновременно играет один audio/video. Запуск другого ставит первый на паузу. Выход из detail/hidden app приостанавливает; позиция сохраняется в памяти текущего клиента, без фона и синхронизации прогресса между устройствами. Original voice можно скачать.

## D09. NoteMemoryCard
Padding16. Plain text16/24, максимум8строк в ленте, затем «Читать полностью». При очень длинном слове `overflow-wrap:anywhere`; переносы сохраняются. Никакой автоматически нарисованной цитаты/звёздочки/категории. Emoji автора сохраняется. Metadata/heart как у медиа. Деталь показывает весь текст и дату.

## D10. BottomNavigation
Три области одинаковой ширины. Левая: House22+«Лента»11. Средняя: Plus24 в круге48 accent-soft, ниже «Добавить»11; мягкий коралл с тёмным знаком, не белый малоконтрастный. Правая: UsersRound22+«Семья»11. Active route text accent-strong, неактивный muted. Tap-area каждой области минимум64×60.

Viewer: центр круг LockKeyhole20 surface-soft и «Просмотр», не button/tab и не keyboard focus. Две рабочие области сохраняют размеры. Нельзя просто скрыть backend-button и оставить возможность создать POST.

## D11. Add sheet
Белая поверхность с верхними radius24, drag handle36×4 muted/decorative, padding20. Заголовок «Что добавить?»18/26 semibold. Close44 справа. Строки60px, gap8, radius12 surface-soft: Image/Video «Фото или видео», FileText «Заметка», Mic «Голосовое в боте». Иконки22 в фоновых кругах36. Внизу коротко «Материалы увидят участники вашей семьи»12/18.

Нет «Событие», «Важная дата», «Первый раз», AI. Escape/back/swipe закрывает с восстановлением focus. Оверлей40%; focus-trap не блокирует Telegram Close навсегда. Не масштабировать весь экран как декоративную 3D-карточку.

## D12. Composer и редактор
Note: header back44 + title18; textarea min160px, font16/24, max8000counter только ближе к лимиту; label«Заметка». Дата/время в компактном поле, умолчание сейчас, можно раскрыть. Fixed primary «Сохранить»48 внизу над keyboard, но не поверх textarea.

Media: системный picker accept точных форматов, 1–10 фото или1видео. Смешанный выбор в Mini App запрещён с понятным текстом; отправлять отдельными записями. Thumbnail rail80px, необязательная подпись, date, сохранить. Progress по файлам и общему состоянию; blocked navigation при отправке с явным подтверждением. Файл не «сохранён», пока backend не подтвердил оригинал. Ошибка не стирает введённую подпись из памяти текущей формы.

Voice: кнопка открывает личный бот; пояснение «Запишите голосовое в чате. Оно появится здесь». Никакого запроса microphone permission WebView в MVP.

Edit: те же поля body/date и expectedVersion. 409 открывает сообщение о конфликте и возможность перечитать новую версию, не молча overwrite. Cancel сохраняет существующий пост неизменным. Source files не заменяются.

## D13. Деталь и media viewer
Detail header: реальный app-back44, title «Воспоминание», overflow44 только full. Media width до max480, contain для portrait в детали (max65dvh), подпись не накладывается на изображение. Автор/полная дата/likes доступны ниже. У full menu «Изменить», «Удалить»; у viewer никаких серых запрещённых действий.

PhotoSwipe загружается по открытию. Фото fit contain, pinch/zoom/sweep поддерживаются библиотекой, close44 сверху в safe area. Всегда есть кнопка закрыть, не только жест. Не размещать внешнюю кнопку «поделиться всем»; save original — явное действие. History/back закрывает viewer раньше ухода из приложения.

Кнопка«Пригласить близкого»48 только owner. Sheet: две radio-cards с пояснениями. Default«Просмотр»: смотреть, скачивать, сердечки. «Полный доступ»: добавлять, редактировать и удалять семейные записи. Ссылка72ч/одноразовая, кнопки«Отправить приглашение»,«Скопировать»,«Отменить ссылку». Не печатать огромный токен на карточке по умолчанию.

Далее: место«Использовано 320 МБ из 2 ГиБ» с прогрессом, help/privacy,«Выйти из семьи» для non-owner. Owner видит способ связи для export/erase (контакт поставляется конфигурацией, без выдуманного username). Никаких тарифов и оплаты.

## D15. Onboarding / приглашение
Заголовок«Соберём вашу семейную ленту». Поля: название семьи, имя ребёнка, необязательная дата рождения, подтверждение timezone. Privacy-consent отдельный unchecked checkbox, ссылка на текст. CTA«Создать семейную ленту». Не просить контакты телефона.

Invite:«Вас приглашают в семью „Наша семья“», ясные права, privacy notice, CTA«Присоединиться». Истёкшее/отозванное/использованное приглашение — самостоятельные состояния без disclosure чужих данных. Знакомому неподтверждённому user не показывать фото семьи как teaser.

## D16. Пустые, загрузочные и ошибочные состояния
Empty feed: нейтральная иконка Image32 в круге64 accent-tint, заголовок18/26 «Здесь появятся ваши воспоминания», текст14/22, primary«Открыть бота» дляfull. Viewer text«Когда близкие добавят первый момент, он появится здесь». Без мнимого демо-поста в реальном аккаунте.

Loading: 2карточки skeleton с зафиксированными aspect ratios, reduced-motion без мерцания. Network error: сохранённые уже видимые карточки не исчезают; banner«Не удалось обновить ленту»+«Повторить». Нет сети — не утверждать, что запись отправлена; offline queue в MVP отсутствует.

Access revoked: очистить family query cache/object URLs, остановить playback, перейти на экран закрытого доступа. Media unavailable: заглушка нужного ratio и retry, не разбитая иконка браузера. Quota:«Место для тестового архива закончилось. Свяжитесь с организатором»; никакой кнопки оплаты.

## D17. Доступность и безопасность рендера
Не использовать цвет как единственный статус. Поля font-size≥16 на iOS против нежелательного zoom. Focus-visible2px accent-strong offset2. Text selection не отключать целиком. System font scale проверять до200%. Не использовать `dangerouslySetInnerHTML` для body. Linkы выводятся безопасным компонентом без автоматического unfurl/preview.

Для private media использовать same-origin auth endpoint, не embed токены. Общий cache не хранит содержимое семьи после выхода. Browser screenshot fixtures только синтетические; testID стабильны и не включают персональные данные.

## D18. Motion / производительность
Обычный transition180ms, dialog220ms; reduced-motion0. Не auto-scroll к новому посту. Album swipe не должен блокировать вертикальный scroll. Lazy image, aspect-ratio заранее, decoding async, first visible photo priority только одна. PhotoSwipe lazy import; heavy FFmpeg только backend, не wasm в браузере.

Цели пилота: первый полезный экран≤3сек на подготовленном тестовом соединении и≤50KB загружаемых данных для текстовой страницы без фото (не весь JS bundle); отсутствие ощутимого скачка карточек. JS bundle measured после baseline; не придумывать цифру lighthouse как доказанную. Feed 20 на страницу, длинный список тест500records; виртуализация не обязательна, пока нет измеренного торможения.

## D19. Визуальная приёмка
Fixture: семья«Наша семья», ребёнок«Варя», дата2026-09-09, note«Сегодня сама придумала историю про облако», photo-caption«Первый раз на море», voice00:24«Смешно сказала: „море большое!“», video00:31. Имена/контент — тестовые.

После внедрения freeze actual screenshots как baseline, не сравнивать их pixel-by-pixel со всей AI-картинкой: у неё иной масштаб и лишние функции.

## D20. Нормативный комплект референсов и растровые иконки
Экранные WebP в `../../references/screens/` — статические визуальные референсы, не работающая программа и не картинка, которую нужно положить вместо HTML. Полная карта экранов и состояний — `../../references/INDEX.md`.
Имена House/Heart/Play и другие в этом документе обозначают семантику, не требование импортировать SVG-библиотеку. Рендерить через собственный `WebpIcon` и `assets/manifest.json`, версии48/72px. Декор, поля и тексты остаются отдельными элементами. Визуальные альтернативы, случайно появившиеся в сырой генерации, не добавляют функций; активные референсы приведены к этому ТЗ.
Изображения состояний загрузки/ошибок — снимки тестовых состояний, а не требования показывать постоянные ошибки. Нейтральный fallback системного шрифта допустим в референсном HTML; при реализации Inter подключается законным публичным пакетом, файлы шрифтов в архиве отсутствуют.
