# Банк идей memoLy

Это постоянное место для мыслей и предложений владельца проекта. Идеи **не являются задачами на реализацию** и не разрешают менять продукт.

## Команда для любого агента

Когда владелец говорит «запиши в идеи», «добавь в идеи» или эквивалентную фразу:

1. Запиши мысль в `docs/ideas/IDEAS.md` максимально близко к словам владельца, без придумывания требований.
2. Если мысль неполная — сохрани как есть, не требуя уточнений. Можно добавить отдельное краткое пояснение, явно помеченное как предположение.
3. Для новой записи добавь следующий свободный ID `IDEA-0001`, `IDEA-0002` и т. д., дату (если известна), статус `Идея` и исходную формулировку.
4. Не удаляй и не переписывай прежние идеи. При уточнении добавь датированное дополнение к существующей записи. Повтор не создавай, если это очевидно та же идея.
5. Сверь свежий `main` перед записью. Работай в своей ветке; при параллельных записях объединяй изменения без потери записей.
6. Сохрани изменение в GitHub через обычный docs-only PR и merge по действующим разрешениям. Не запускай production deploy ради документации без runtime-эффекта.
7. Подтверди сохранение только после успешного merge, указав ID идеи и ссылку на GitHub. Если нет доступа к записи — честно сообщи, что идея ещё не сохранена.

Не добавляй реальные семейные фотографии, секреты, токены, личные данные пользователей и конфиденциальные материалы.

## Статусы

`Идея` — только записана; `На обсуждении` — владелец обсуждает; `Одобрена` — владелец отдельно утвердил; `В работе` — назначена разработка; `Реализована` — подтверждена доставка; `Отложена` — пока не делать.

Статус меняется только по прямому решению владельца или подтверждённому факту доставки уже назначенной задачи.

Идеи могут быть как техническими, так и продуктовыми. Хранилище — обычные Markdown-файлы в GitHub; для просмотра достаточно открыть `IDEAS.md`.
