Task: `MEMOLY-UI-V4-PIXEL-IMPLEMENTATION`.

Это ТЗ для переноса принятого HTML-макета v4 в **существующий React-продукт**, а не разрешение заменить приложение статической демонстрацией. Дата подготовки: 18 октября 2026. Проверенный при подготовке main: `f0a4e8ba3fa174f43c661ab2a70a6b744c6543f4`; production SHA этим документом не подтверждается.

## Читать по порядку

1. Корневой `AGENTS.md` актуального main и применимый teamlead skill.

Пакет документации не подключается к Vite, Service Worker, production routing или серверу. Не импортировать его фикстуры в продукт. В этой публикации не разрешены merge, deploy или изменение production.

## Что зафиксировано

Без логотипа и слогана в повседневной шапке. Шапка 96 CSS px с фоном, луной, облаками и звёздами. Аватар, имя, возраст и настройки находятся в одном компактном блоке. Нет дополнительной пустоты над шапкой.

Воспоминания без внешних белых карточек, рамок и теней. Автор и время — в компактной строке; подписи и реакции небольшие. Дата — 12/17 px. Медиа целиком, без обрезки; рамка стабильна внутри одной публикации. Нижняя навигация — спокойная полоса 62 px плюс единожды учтённый safe area. Семья — компактный профиль, сначала участники, одно приглашение, затем канал MAX.

Смена оформления не изменяет авторизацию, семейные права, импорт MAX, подписи, оригинальные даты, дедупликацию, unread-семантику, запросы и кэш приватных медиа, координацию проигрывателей и общую загрузку аватаров.

## Иерархия требований

Безопасность, реальные пользовательские данные, существующие права и доступность → явно перечисленные production-правила SPEC → эталон v4 и его CSS → старые дизайн-документы. Это не разрешение придумывать новый дизайн: расхождение оформлять как конкретный блокер, а не решать заменой макета.

`reference.html` — визуальный контракт обычных состояний, **не архитектура production**. Его hash-ссылки, CSS `:target`, чекбоксы реакций, заглушки видео/голоса, тестовые числа и настройки сравнения никогда не заменяют React-контроллеры и API. Не переносить desktop-рамку телефона и поясняющий текст рядом с ней.

## Приватность публичного примера

Размеры, компоновка, CSS и все экраны сохранены из принятого v4. Семейные фотографии/аватары заменены нейтральными геометрическими фикстурами с теми же исходными пропорциями; имена демонстрационные. Иллюстрация шапки сохранена. Векторные пиктограммы прототипа растеризованы в WebP RGBA для публичного примера; в продукте использовать штатный `WebpIcon` и согласованный набор.

Содержимое фотографий не является CSS-эталоном и не должно заменяться в реальном приложении. Для screenshot-тестов сравнивать одинаковые синтетические данные на эталоне и production-компонентах.

Chromium, DPR=1, viewport 390×844 CSS px, safe area=0, масштаб текста 100%: шапка y=0/h=96; первая область медиа x=16/y=175/w=358/h=216.1875; нижняя панель y=782/h=62. На экране семьи: toolbar h=58, профиль y=70/h=96, заголовок участников y=191, первая строка y=221/h=71, приглашение y=379/h=46.

Проверены публичный эталон и совпадение ключевых геометрических точек с оригинальным v4 на ширинах 320, 390, 430 и 1280; базовая навигация, реакция, просмотрщик и переключатель пропорций работают без JavaScript. Это **не** тесты production React/MAX, настоящего iPhone, backend, ACL или медиа.

Небольшие обязательные отличия production для контраста, доступных зон нажатия и длинного/увеличенного текста явно определены в SPEC. Они не разрешают менять композицию по вкусу.
