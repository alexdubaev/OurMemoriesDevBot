# Modern family storybook / cozy scrapbook minimal

The family album is the subject. Large photographs own the Feed; text, author and reactions
create quiet context. Notes and voice share the same MemoryCard anatomy as photo and video.
There is no separate visual system for each content type.

- Warm milk canvas, soft paper surfaces, deep neutral ink.
- One restrained pastel accent per theme. Geometry never changes with the theme.
- System sans, weight 400 for reading, 500 for people and names, 600 for headings/actions.
- Generous readable spacing from one scale. No card-in-card decoration or handwritten font.
- The official memoLy logo stays recognisable; no new branding.
- One FamilyHero supplies logo, “Все семьи”, child portrait/name/age and album privacy.
  Feed reserves the same action slot that Family uses for settings.
- Persistent bottom navigation: Лента / Добавить / Семья. Add is the quiet primary centre action.
- Safe areas and touch targets are part of primitives, not per-screen fixes.
- Photos are shown naturally and fully in the viewer. Originals are never changed.
- Motion is short opacity/translate/press feedback; reduced motion removes it.

Welcome uses a fictional family photograph as its emotional opening. No noisy illustration,
floating ornament or CSS drawing is needed. The family view uses rows rather than nested cards.
Channel and invite use one purposeful surface each. Buttons and error copy stay consistent.
