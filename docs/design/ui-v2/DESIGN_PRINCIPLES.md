# A warm family album

The owner supplied the composition reference: watercolor profile header, round child portrait,
large family photograph, soft cream card and floating bottom navigation.
The owner subsequently removed separate color themes from scope and will provide cover images.

- One cream/sage palette; optional cover artwork never changes button, text or surface colors.
- The official memoLy logo and real HTML text remain independent of raster artwork.
- Shared FamilyHero contains back/settings, centered brand/tagline and child identity.
- Cover images use object-fit: cover in a stable header. The owner should leave quiet space
  behind the logo and child details. Actual artwork/crop/readability must be checked on arrival.
- MemoryCard uses a photo author avatar, inset rounded media, caption and existing reactions.
- Keep the unread filter in a small month row; preserve existing functionality.
- Floating navigation uses a selected pill and round filled Add button with 44px minimum targets.
- Photo, note, voice and video share one card system. Portrait previews retain a 300px cap;
  the viewer keeps the complete image.
- All pictures/icons are raster; no SVG, icon fonts or CSS illustrations.
- The Lab's family photographs are generated fictional demo material. User photos are not replaced.
- No comments/bookmark features or fake phone status/home bars are introduced from the reference.
- Short press/fade transitions, reduced motion and safe-area inputs remain supported.

Header artwork is intentionally pending the owner's files. No alternate header was generated.
