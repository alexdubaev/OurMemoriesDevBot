# memoLy design context

## Register
product

## Users and purpose
Parents and invited relatives saving and revisiting a child's memories on a phone.
Older relatives need readable copy, clear actions and comfortable touch targets.
Photos, video, notes and voices form a private family album.

## Accepted direction
The owner's latest visual reference uses a cream canvas, softly rounded memory cards,
large warm photographs, a watercolor botanical profile cover and circular child portrait.
Preserve the official memoLy logo. One sage accent palette applies to every screen.
Only the profile cover changes; the owner is generating those images.
Earlier rejected concepts are superseded by this concrete reference.

## Principles
1. Let family photographs and the child's identity lead.
2. Put real text and controls over a replaceable raster cover.
3. Keep card anatomy and palette consistent across screens and covers.
4. Preserve the actual product actions and access roles.
5. Minimum 44px targets, accessible contrast, keyboard focus and reduced motion.

Source: owner reference and decisions in this conversation; project brand and asset guides.
Context is scoped to design documentation under the task's allowed paths.
