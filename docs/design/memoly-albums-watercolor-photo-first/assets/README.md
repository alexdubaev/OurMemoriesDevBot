# Original watercolor decorative assets (sanitized)

These are actual watercolor assets from the approved first mockup, not emoji or approximate vector substitutes. They contain no family photographs.

- palette.webp — small painter's palette used in the workshop title
- bear.webp — bear illustration close to the gallery
- rabbit.webp — bunny accent near the end of the page
- hero-hills.webp — pastel green landscape used in the compact header
- sprig.webp — small foliage separator

Use with the existing design spec in ../SPEC.md. Real user photographs must be loaded from memoLy private media at runtime and must never be committed to this design package. Do not use the schematic data-URI SVGs in reference.html as the final artistic illustration. The full source archive is being placed alongside this file.
