# memoLy — акварельные внутренние альбомы

Утверждён ПЕРВЫЙ вариант: палитра, мишка около фотографий, зайчик внизу, светлый фон и мягкие зелёные холмы. Приоритет — фотографии, а не элементы управления.

## Материалы
- SPEC.md — требования и запреты.
- IMPLEMENTATION.md — минимальный путь переноса в React.
- ACCEPTANCE.md — приёмка и проверки.
- START_PROMPT.md — стартовое задание Codex.
- reference.html — интерактивный без JavaScript, обезличенный структурный эталон.

Примечание о приватности: в локальном исходном HTML есть снимки из личных скриншотов владельца. Они не публикуются на GitHub. Репозиторный эталон использует нейтральные иллюстрации. Полный выбранный оригинал сохранён у владельца как memoly-albums-watercolor-nojs.html, SHA256 4997a52f28972f661cc0411fbc5832f136fa8f3a50d8aa13a89129df0ba68fa2. Репозиторный HTML помогает воспроизвести структуру, но не подменяет живую media pipeline.

Макет использует CSS-состояния, ссылки и details, без скриптов. Он не умеет сохранять данные, загружать фото, изменять реальный альбом или реализовать двухпальцевое масштабирование. В production сохранить уже существующую React-логику.

Каталог альбомов из рабочего приложения НЕ менять. Оформление касается только внутренних страниц Мастерской, Первого года, Первых открытий и свободного альбома.

Это docs/reference-only пакет. Main и production этим PR не изменяются.

## Дополнение после проверки агентом (2026-11-04)
Полный **обезличенный автономный акварельный HTML**: [reference-full-safe.html](reference-full-safe.html). В него встроены настоящие акварельные palette/bear/rabbit/hero-hills/sprig (без запросов к сети); действуют переходы и CSS-фильтры без JavaScript. Для внедрения в React отдельно дан [watercolor-overrides.css](watercolor-overrides.css) с ссылками на эти WebP в папке assets/. Каталог приложения не меняется. Семейные фото заменены синтетическими рисунками; по сравнению с локальным исходным макетом есть визуальные отличия только в демонстрационных изображениях.


## Полный пакет — опубликован на GitHub 2026-11-04

**Агенту не нужно спрашивать владельца о ZIP, локальном пути или вложении.** В этой ветке доступны:
- [Полный автономный акварельный HTML](reference-full-safe.html) — самодостаточный кликабельный референс без JavaScript с вшитыми оригинальными декоративными WebP (палитра, медвежонок, зайчик, холмы, веточка), четырьмя видами внутренних альбомов и синтетическими медиа вместо частных семейных фотографий.
- [Полный ZIP-пакет](memoly-watercolor-full-safe-source.zip) — HTML, stylesheet для React, оригинальные пять WebP, README, SPEC, ACCEPTANCE. В архиве 10 файлов; офлайн HTML не требует отдельного сервера.
- [CSS-слой](watercolor-overrides.css), [assets](assets/) для использования в React.

Исходный частный HTML из чата содержит семейные фотографии и не публикуется. GitHub-версия намеренно обезличена, а не побайтно идентична частному файлу, но сохраняет основные экраны, интерактивные демонстрационные переходы и акварельные художественные элементы первого утверждённого варианта.

Для текущей реализации комментариев и реакций к AlbumEntry действует **последнее объединённое ТЗ владельца**; старые ограничения этого docs-only пакета про UI-only/FONTEND не применимы к новой серверной части. Для неё нужно FULL; не менять сам каталог Альбомы.
