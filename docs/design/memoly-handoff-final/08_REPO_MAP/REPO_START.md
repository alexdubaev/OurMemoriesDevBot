# Наши воспоминания — рабочий пакет MVP
**Пакет 2.4 · 09.09.2026 · классическая светлая лента · закрытый пилот.**

## Первое действие
Распакуйте **всю папку** из ZIP. Откройте [WORKPLAN.xlsx](../../../../WORKPLAN.xlsx). Не открывайте Excel непосредственно из ZIP: относительным ссылкам нужны соседние файлы. Если Excel предупреждает об открытии локального файла, проверяйте его путь; все внутренние ссылки ведут в этот пакет. Markdown откроется приложением, назначенным вашей системой.

В Excel: «Старт» — объяснение; «План» — что отдавать агентам и в каком порядке; «Все файлы» — полный каталог; «Экраны» — изображения; «Параллельно» — границы команд; «Источники» — проверенные внешние ссылки.

## Что передать Codex
1. Открыть новый репозиторий проекта; копировать **AGENTS.md** в его корень после согласованного объединения с необходимыми инструкциями Vibe. Имя именно `AGENTS.md`, не отдельная копия `agents.md`: в Windows такие имена могут конфликтовать, а Codex использует стандартное верхнее написание.
2. Папки `docs/mvp`, `assets`, `references` и `templates` сохранить с относительной структурой. Только runtime-файлы из `assets/icons` копируются в публичные assets приложения; demo и screenshots в production не включать.
3. Передать [первый запрос](../../../../docs/mvp/08_CODEX_START.md), затем один текущий блок из [карты задач](../../../../docs/mvp/TASK_INDEX.md).
4. Исторические материалы не входят в рабочий проект и не используются как ТЗ.

## Продукт
Личный бот → фото, видео, голос и текст → одна приватная семейная лента. Полный доступ либо просмотр с лайками. Никаких AI, чтения групп, платежей, календаря, поиска, отдельной галереи, социальных комментариев и реализации iOS/Android/VK в первом MVP.

Для голосовых зафиксированы Play/Pause, waveform/progress, длительность и подпись; для видео — poster, Play/Pause, seek, время и fullscreen. Нативный Telegram-плеер остаётся только в самом чате. Собственный decoder/media-engine и новый тяжёлый player framework в MVP не разрабатываются.

## Параллельность
Только две разрешённые волны: **A = 03 + 06**, **B = 05 + 08**. Одинаковая заливка строк в Excel означает одну волну, но не разрешает запуск до принятых зависимостей. После волны интегратор последовательно принимает обе ветки и проверяет их совместно. Общие файлы имеют одного владельца. Подробнее: [PARALLEL_WORK.md](../../../../docs/mvp/PARALLEL_WORK.md).
