# FEED-ONE-CONTAINER · решение владельца от 30 сентября 2026

## Требования и план

ONE MEMORY = ONE CONTAINER. Для photo, video, mixed media, note и voice остаётся один внешний контейнер записи: шапка с автором, аватаром, временем и меню → контент → лайк и компактные служебные элементы.

Внутри записи нет второй карточки, рамки или панели: убрать внутренние rounded boxes медиа, панель под каруселью, отдельную карточку заметки и поверхность капсулы голосового. Текст остаётся настоящим HTML, медиа и воспроизведение сохраняют существующие механизмы. Кнопки управления и focus outline не считаются дополнительной карточкой.

Убрать верхние фильтры по типам. Единственный переключатель ленты — компактный «Все / Непросмотренные», с существующей проверкой доступности режима непросмотренных. Индикатор карусели — точки вместо видимого «1 / 3»; номер активного слайда остаётся доступен вспомогательным технологиям.

Это позднейшее прямое решение владельца заменяет несовместимые указания о композиции карточек, фильтрах типов и числовом индикаторе в прежних design.md и референсах. Полноэкранные viewer и detail не требуют изменения композиции по этой задаче.

1. Общая структура и CSS карточки: убрать внутренние поверхности для всех пяти типов.
2. Навигация ленты: убрать типовые фильтры и исключить скрытое ограничение по типу, сохранить непросмотренные.
3. Карусель: точки синхронизированы с активным слайдом; навигация, доступность и остановка воспроизведения сохранены.
4. Проверки: baseline и итоговый webapp test, typecheck, build; целевая визуальная проверка и независимое ревью.
