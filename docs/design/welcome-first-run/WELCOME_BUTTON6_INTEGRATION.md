Только для близких.» и замок; также прежнее «Личная история, которой делятся только с близкими», приветствие-кicker, наклонный слоган, повторное описание фото и финальное «Создано с теплом». **Запрет относится к UI**, не к обсуждению этих фраз в документации.

Высота ориентир 64px; на коротком экране 58px, стрелка 48px/44px; адаптировать по условиям реального экрана, не прибивать размеры как ломкий тест. Не заменять на полностью зелёную кнопку и не добавлять сердце.

## Как смотреть локальный эталон

Из checkout репозитория открой `docs/design/welcome-first-run/button6-reference.html` в браузере (локальный file:// подойдёт для WebP). Для точного Comfortaa нужен интернет на Google Fonts **только у эталона**; production должен использовать локальный шрифт. Если сеть закрыта, эталон покажет fallback, но исходные WebP останутся рабочими.

**Ожидаемый handoff:** PR/merge SHA, проверенные мобильные размеры, визуальное сравнение, результат проверки кнопки и реального onComplete, статус нативных iOS/MAX проверок, отметка «deploy: NO».
