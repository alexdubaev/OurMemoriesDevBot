Ревью: исполнитель, head SHA, findings/resolution.

Перед merge в `main` приложить результат `bun run verify:local` для точного проверенного source SHA/tree. PR merge не вызывает локальный pre-push hook; после merge записать merge SHA и подтвердить, что проверенный продуктовый source содержится в нём. Изменение только документации/метаданных не требует повторного запуска неизменённых продуктовых проверок. Если проверка недоступна из-за окружения, отметить её BLOCKED с причиной; не считать её пройденной.
