|---|---|---|

UI: ссылки на actual screenshots + сопоставление с ref IDs.
Ревью: исполнитель, head SHA, findings/resolution.

Перед merge указать профиль FAST/STANDARD/FULL, риск-основание, фактические команды, результат и точный source SHA/tree. FULL обязателен для auth/session, ACL, приватных медиа, schema/data, критических транзакций, публичных контрактов и критической инфраструктуры. Pre-push запускает классификацию относительно remote SHA для main/master; PR merge hook не запускает. Перед production deploy требуется FULL на точном итоговом release SHA со всеми включёнными изменениями. Dry-run не является PASS. Недоступные обязательные проверки отмечаются BLOCKED, пропуск не считается PASS.
