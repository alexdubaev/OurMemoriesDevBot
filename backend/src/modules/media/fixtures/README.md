# Media test fixtures

`heic-exif-orientation.heic` is the small HEIC/EXIF fixture from
`gen2brain/heic/testdata/test_exif.heic`. It is used only in backend tests to prove that the
pinned HEIC decoder handles a real HEVC image carrying EXIF orientation. The upstream project is
MIT licensed: https://github.com/gen2brain/heic
